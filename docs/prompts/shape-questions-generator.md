# برومبت احترافي لتوليد أسئلة الأشكال لمنصة تسنيم التعليمية

برومبت جاهز لأي أداة ذكاء اصطناعي قوية في البرمجة (مثل Claude أو ChatGPT أو Gemini). الهدف أن تنتج الأداة دفعة جديدة من أسئلة الأشكال **بالصيغة البرمجية نفسها التي تستخدمها المنصة**، فتُضاف إلى الموقع مباشرة دون إعادة كتابة.

---

## طريقة الاستخدام (3 خطوات)

1. **انسخ البرومبت** من القسم التالي كاملًا.
2. **عدّل المتغيرات** في أول البرومبت: رقم الدفعة، وعدد الأسئلة، والأنواع المطلوبة، وتوزيع الصعوبة.
3. **ألصق الناتج** في ملف جديد `src/data/questions/shapes/batchN.ts`، أو أرسله إلى Claude Code ليدمجه ويشغّل الاختبارات ويراجع الرسوم بصريًا قبل النشر.

> **مهم:** أداة الذكاء الاصطناعي قد تخطئ. لا تنشر أي سؤال قبل أن يجتاز `npm test`، وقبل مراجعته بالنظر (الرسم + الإجابة + الشرح).

## البرومبت

````text
# الدور
أنت مصمّم خبير لأسئلة التفكير غير اللفظي (أسئلة الأشكال) لطلاب الصف السادس (11–12 سنة)،
ومبرمج TypeScript دقيق. تكتب أسئلة أصلية بالعربية الفصحى المبسّطة، وتبنيها كبيانات برمجية
تستخدم مكتبة رسم جاهزة، بحيث تكون الإجابة الصحيحة محسوبة من القاعدة نفسها لا مكتوبة يدويًا.

# المهمة
أنشئ ملف TypeScript واحدًا كاملًا اسمه `batch{{N}}.ts` يحتوي {{COUNT}} سؤال أشكال أصليًا جديدًا.
- رمز معرّفات هذه الدفعة: الحرف «{{LETTER}}» (مثلًا pat-{{LETTER}}01، spa-{{LETTER}}01).
- الأنواع المطلوبة: {{TYPES}}
- توزيع الصعوبة المطلوب: {{DIFFICULTY_MIX}}  (1 = سهل، 2 = متوسط، 3 = متقدّم)
- توزيع المجالات: {{TOPICS_MIX}}

# السياق
منصة تدريبية عربية (من اليمين إلى اليسار) لطلاب الصف السادس في المدارس العربية، تستعد
لاختبارات برامج الموهوبين. فيها حاليًا 96 سؤال أشكال من الأنواع التالية، فلا تكرّرها بالفكرة نفسها:
سلاسل (دوران سهم، عدد نقاط وأضلاع، مربع يتحرك على الإطار، تغيّران معًا)، وجداول (تراكب،
مشترك، أحدهما فقط، حذف، مجموع وضرب نقاط، مربع لاتيني، شكل من الأول ولون من الثاني)،
وتناظر (لون، دوران، مرآة، نصف دورة مع عكس الألوان)، والشكل المختلف، ومرايا عمودية وأفقية،
وطيّ ورق (مرة، مرتين، على القطر)، ومسنّنات وبكرات، وشبكات مكعّب، وعدّ مثلثات ومستطيلات
ومربعات، ومكعبات مجسّمة، وقطاعات دائرية، ونجوم، وساعات، وموازين، وتنقّل على شبكة، وقطعة
تكمل المربع، ورسم دون رفع القلم، وطرق أقصر، وإكمال تماثل، وشفافيات، ومعادلات أشكال.

# شروط الأصالة (إلزامية)
- كل سؤال من تصميمك بالكامل. لا تنسخ ولا تعيد صياغة أسئلة من اختبارات منشورة أو تجارية
  (مثل CogAT وRaven وكتب التحضير) أو من مواقع الإنترنت أو بنوك الصور.
- أنواع القواعد العامة (الدوران، التراكب، التماثل...) أفكار شائعة يجوز استخدامها، لكن
  بأشكال وتركيبات ومعطيات جديدة.
- لا تذكر وزارة التربية أو أي جهة رسمية، ولا تكتب أن السؤال «رسمي» أو «من الامتحان».

# الأنواع (Types) — هكذا تبدو بنية السؤال
```ts
type Paint = "black" | "white" | "gray" | "blue" | "light" | "red" | "green" | "yellow" | "none";
type Shape =
  | { t: "circle"; cx: number; cy: number; r: number; fill?: Paint; dash?: boolean }
  | { t: "rect"; x: number; y: number; w: number; h: number; fill?: Paint; dash?: boolean }
  | { t: "poly"; pts: number[]; fill?: Paint }
  | { t: "line"; x1: number; y1: number; x2: number; y2: number; dash?: boolean }
  | { t: "path"; d: string; fill?: Paint };
interface Glyph { shapes: Shape[]; rotate?: number }   // rotate بالدرجات مع عقارب الساعة حول (50،50)
type Visual =
  | { layout: "sequence"; cells: (Glyph | null)[] }               // null = خانة «؟»
  | { layout: "matrix"; cols: number; cells: (Glyph | null)[] }
  | { layout: "analogy"; cells: [Glyph, Glyph, Glyph] }           // أ : ب :: ج : ؟
  | { layout: "mirror"; glyph: Glyph; axis?: "vertical" | "horizontal" }
  | { layout: "group"; cells: Glyph[]; caption?: string }         // أمثلة على قاعدة، أو موازين
  | { layout: "single"; glyph: Glyph };
// كل سؤال (بعد defineOriginalQuestions يُضاف topic وsource تلقائيًا):
{
  id: string;                 // فريد، مثل "spa-{{LETTER}}01"
  difficulty: 1 | 2 | 3;
  prompt: string;             // نص السؤال
  visual?: Visual;            // رسم السؤال
  optionVisuals?: Glyph[];    // إذا كانت الخيارات رسومًا (4 رسوم)
  options: string[];          // 4 خيارات نصية؛ إذا وُجدت optionVisuals فهي وصف لكل رسم
  answer: number;             // رقم الخيار الصحيح من 0 إلى 3
  explanation: string;        // شرح الحل
}
```

# مكتبة الرسم المتاحة (استوردها من "./kit" فقط، ولا تخترع دوال غير موجودة)
الإحداثيات داخل مربع 100×100، والمركز (50، 50). الدوران الموجب = مع عقارب الساعة.

أشكال أساسية (تُرجع Shape):
- `circle(r=32, fill="white", cx=50, cy=50)`
- `triangle(r=36, fill, cx=50, cy=52)` ، `square(r=36, fill, cx, cy)` ، `diamond(r=36, fill, cx, cy)`
  (r = نصف قطر الدائرة المحيطة)
- `pentagon(r, fill)` ، `hexagon(r, fill)` ، `heptagon(r, fill)`
- `ngon(n, r=34, fill="white", offsetDeg=-90, cx=50, cy=50)` — مضلع منتظم بعدد أضلاع n
- `rectangle(fill)` — مستطيل أفقي ثابت
- `dot(cx, cy, r=6, fill="black")`
- `star(n, fill="yellow", ro=38, ri=17)` — نجمة بعدد رؤوس n
- `lineThrough(deg, len=38)` — خط يمر بالمركز (0 = عمودي، 90 = أفقي)
- `gear(cx, cy, r=12, teeth=8)` ، `curvedArrow(cx, cy, r, clockwise=true)` (تُرجع Shape[])
- `arrowAt(cx, cy, deg, s=0.45, fill="black")` — سهم صغير في أي موضع

مركّبات (تُرجع Glyph):
- `glyph(...shapes)` ، `combine(...glyphs)` ، `rotate(glyph, deg)`
- `arrow(deg)` — سهم كبير (0 = إلى الأعلى، 90 = إلى اليمين)
- `dots(n)` (1–6 بترتيب النرد) ، `manyDots(n)` (1–9)
- `spread(n, (cx, cy) => Shape)` — من 1 إلى 4 أشكال صغيرة موزّعة
- `pie(n, filledIndexes, fill="blue")` — دائرة من n قطاعات، القطاع 0 يبدأ من الأعلى مع عقارب الساعة
- `grid(cells, cols=3, rows=3, fill="black")` — شبكة، الخانات المختارة ملوّنة.
  الترقيم صفًّا صفًّا من الزاوية العلوية اليسرى: 3×3 → 0 1 2 / 3 4 5 / 6 7 8
- `colorGrid({رقم_الخانة: لون}, cols=3, rows=3)` — شبكة بعدة ألوان
- `net(cells, cols, rows)` — يرسم الخانات المختارة فقط (قطع، شبكات مكعب)
- `clock(hourDeg, minuteDeg)` — ساعة (كل رقم = 30°)
- `isoCubes([[x, y, z], ...])` — مكعبات مجسّمة
- `balance(rightItems, leftItems)` — ميزان متوازن؛ العناصر "circle" | "square" | "triangle" (حتى 6 في الكفة)
- `pulleys()` — ثلاث بكرات بحزام متقاطع ثم مستقيم
- `polyWithDots(sides, n)` — مضلع بداخله n نقاط
- `streets(cols, rows)` — شبكة شوارع ببداية خضراء (أسفل اليسار) ونهاية حمراء (أعلى اليمين)
- `graphGlyph({ nodes: {اسم: [x, y]}, edges: [[أ, ب], ...] })` — رسم من نقاط وخطوط

عمليات محسوبة (استخدمها لحساب الإجابة والمشتّتات بدل كتابتها يدويًا):
- على خانات 3×3: `union, intersect, xor, difference, complement, rot90, rot180, rot270, mirror, flipV`
  و`BORDER_CW = [0,1,2,5,8,7,6,3]` (الإطار مع عقارب الساعة)
- على خانات n×n: `gMirror(c, n), gFlipV(c, n), gRot90(c, n), gComplement(c, n)`
- على خرائط الألوان: `mapRot90, mapRot180, mapRot270, mapMirror, mapFlipV, mapSwap(m, a, b)`
- `oddVertices(graph)` — عدد النقاط ذات الخطوط الفردية (0 أو 2 = يمكن الرسم دون رفع القلم)

# اتفاقيات العرض (مهمة جدًا)
- المنصة من اليمين إلى اليسار: الخانة الأولى في `sequence` تظهر **على اليمين**، وكل صف في
  `matrix` يُقرأ من اليمين. لذلك اكتب في نص السؤال: «(تُقرأ السلسلة من اليمين إلى اليسار)».
- داخل الرسم نفسه لا ينعكس شيء: «يمين» و«يسار» و«أعلى» تعني الاتجاهات الحقيقية على الشاشة.
- لا تكتب أي نص أو أرقام داخل الرسوم. الأرقام والكلمات في prompt وoptions وexplanation فقط.
- التعابير الرياضية في النصوص تُحاط بعلامتي $...$ لتُعرض من اليسار إلى اليمين، مثل: $3 + 4 = 7$.
- لا تستخدم Markdown داخل النصوص (لا ** ولا #).

# معايير جودة السؤال
1. **قاعدة واحدة واضحة** يمكن شرحها في جملتين، ولا تحتمل الإجابة تفسيرًا آخر مقنعًا.
   إذا وُجد تفسيران محتملان، أضف خانة أو صفًّا يحسم بينهما (مثل صف يميّز الجمع من الضرب).
2. **4 خيارات مختلفة كلها** (لا يتطابق رسمان أبدًا). وكل مشتّت يمثّل خطأً محددًا يقع فيه
   الطالب: تطبيق نصف القاعدة، أو الاتجاه المعاكس، أو المرآة بدل الدوران، أو القاعدة الخطأ
   (مثل الاتحاد بدل المشترك)، أو خطأ في العدّ بواحد.
3. احسب الإجابة والمشتّتات **بالدوال** (مثل `grid(xor(A, B))`)، لا بأرقام خانات مكتوبة يدويًا.
4. الإجابة ليست نسخة من آخر خانة ظاهرة في السؤال.
5. في أسئلة الدوران والمرآة استخدم أشكالًا **غير متماثلة**، وإلا تطابق خياران.
6. وزّع موضع الإجابة الصحيحة (answer) بين 0 و1 و2 و3.
7. **وصف الخيارات (options)** يكون وصفًا للمحتوى، مثل «مثلث أبيض يشير إلى اليسار»،
   وليس للموضع، مثل «الخيار الثالث»، لأن المنصة تخلط ترتيب الخيارات.
8. **الشرح:** 1–3 جمل بالعربية الفصحى المبسّطة: اذكر القاعدة، ثم طبّقها على الخانة المجهولة.
   نبرة مشجّعة، دون عبارات مثل «هذا سهل» أو «كما هو واضح».
9. **الصعوبة:**
   - سهل (1): قاعدة واحدة بتغيير واحد واضح.
   - متوسط (2): قاعدة واحدة تحتاج انتباهًا، أو قاعدتان بسيطتان.
   - متقدّم (3): قاعدتان تعملان معًا، أو عملية ذهنية (تدوير، طيّ، مجسّم مخفي).
10. ملاءمة العمر: لا مفاهيم فوق مستوى الصف السادس، ولا أشكال صغيرة جدًا (الحد الأدنى r ≈ 5).
11. نص السؤال (prompt) مختصر وواضح، ويحدد المطلوب بدقة (مثل «دون تدوير أو قلب» عند الحاجة).
````

## أمثلة لملء المتغيرات

| المتغير | مثال |
|---|---|
| `{{N}}` | `4` |
| `{{LETTER}}` | `i` (الدفعات السابقة استخدمت f وg وh) |
| `{{COUNT}}` | `20` |
| `{{TYPES}}` | `«الظل والإسقاط من الأعلى، وتركيب قطعتين لتكوين شكل، وتكرار نمط على شريط، وسلاسل بتغيّر ثلاث صفات معًا، وجداول بقاعدة عددية على الأضلاع»` |
| `{{DIFFICULTY_MIX}}` | `«5 سهلة، 9 متوسطة، 6 متقدمة»` |
| `{{TOPICS_MIX}}` | `«8 أنماط، 9 مكاني، 2 منطق، 1 حل مشكلات»` |

### أفكار لأنواع جديدة لم تُستخدم بعد
- **المنظر من الأعلى** لمجسّم من مكعبات (ارسم الخيارات كشبكات `grid`).
- **تركيب قطعتين** لتكوين مربع أو مستطيل (القطع بـ `net`).
- **الشكل المخفي:** أي خيار يحتوي الشكل الصغير كما هو.
- **العدّ المزدوج:** عدد الأشكال × عدد الأضلاع في جدول.
- **التحويلات المتتالية:** مرآة ثم دوران، والسؤال عن الناتج.
- **سلاسل بثلاث صفات** تتغير معًا: اللون والعدد والدوران.
- **ترميز الأشكال:** كل شكل يرمز إلى عملية، مثل الدائرة = تدوير ربع دورة.

## بعد استلام الناتج

1. ضع الملف في `src/data/questions/shapes/batchN.ts`.
2. أضف المجموعات المصدَّرة إلى `QUESTION_BANK` في `src/data/questions/index.ts`.
3. شغّل الفحوص: `npm run typecheck` ثم `npm test`. اختبارات البنك تكشف تلقائيًا:
   المعرّفات المكررة، والخيارات المتطابقة، والإجابة خارج المدى، وعلامات $ غير المزدوجة.
4. **راجع كل سؤال بالنظر:** هل الرسم واضح؟ هل الإجابة صحيحة فعلًا؟ هل يوجد خيار آخر يمكن الدفاع عنه؟
5. أضف اختبارات خاصة للأسئلة الحساسة (التماثل، الدوران، العدّ) في `tests/shape-questions.test.ts`.

أو اختصر كل ذلك: أرسل الملف إلى Claude Code واكتب: «ادمج هذه الدفعة، وراجعها بصريًا، واختبرها، وأصلح أي خطأ».
