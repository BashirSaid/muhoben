# منصة تسنيم التعليمية

منصة ويب تفاعلية باللغة العربية (من اليمين إلى اليسار) لتدريب طلاب الصف السادس في المدارس العربية على مهارات التفكير والاستدلال وحل المسائل، ضمن برنامج من **30 يومًا**، استعدادًا لاختبارات القبول في برامج الموهوبين عند الانتقال إلى الصف السابع.

> ⚠️ **تنبيه:** جميع الدروس والأسئلة **أصلية من إعداد المنصة** لأغراض التدريب. ليست أسئلة رسمية، ولم تُنسخ من امتحانات منشورة، ولا تُنسب إلى وزارة التربية والتعليم. تقسيم المجالات وعدد الأسئلة ومدة الاختبارات اجتهاد تدريبي **لم يُتحقَّق من مطابقته** لمبنى الامتحان الرسمي المعتمد حاليًا.

## المزايا

- **خطة 30 يومًا**: 24 يوم دروس (4 أيام لكل مجال بمستويات متدرجة) + 4 أيام مراجعة + يوم لاستراتيجيات الامتحان + اختبار شامل نهائي.
- **ستة مجالات**: التفكير المنطقي والاستدلال · الأنماط والمتتاليات · العلاقات اللفظية وفهم النصوص · التفكير الكمي · الأشكال والعلاقات المكانية · حل المشكلات والاستنتاج.
- **كل يوم**: أهداف، ودروس قصيرة، وأمثلة محلولة خطوة بخطوة، ونصيحة، وأسئلة تدريبية مع شرح فوري.
- **بنك الأسئلة**: 146 سؤالًا أصليًا متعدد الخيارات بثلاثة مستويات (سهل/متوسط/متقدّم)، مع شرح مبسّط لكل سؤال، ورسوم SVG للأسئلة المكانية.
- **الاختبارات**: تدريب يومي، وتدريب حر (اختيار المجال والمستوى والعدد)، واختبار قصير شامل (18 سؤالًا / 22 دقيقة)، واختبار شامل (30 سؤالًا / 40 دقيقة) بمؤقت وتسليم تلقائي عند انتهاء الوقت.
- **منع التكرار**: لا يتكرر السؤال داخل الاختبار الواحد، وتُفضَّل الأسئلة التي لم يرها الطالب من قبل، وتُخلط الخيارات في كل محاولة.
- **التقارير**: النتيجة والنسبة، والأداء حسب المجال، ونقاط القوة والمواضيع التي تحتاج إلى تحسين، ومراجعة الأخطاء مع الشرح.
- **لوحة الطالب**: اليوم الحالي، ونسبة إنجاز الخطة، وعدد الأسئلة المُجاب عنها، والنتائج السابقة، والمستوى في كل مجال، والخطوات المقترحة.
- **تجربة مشجّعة**: رسائل إيجابية، ولا ترتيب ولا مقارنة بين الطلاب.

## الخصوصية والتخزين

- لا يوجد تسجيل دخول، ولا تُجمع أي بيانات شخصية (لا اسم، ولا بريد، ولا رقم هوية).
- يُحفظ التقدّم في **`localStorage` الخاص بمتصفح الجهاز فقط**. هذا **ليس تخزينًا مركزيًا**: لا ينتقل إلى جهاز آخر، وقد يُحذف عند مسح بيانات المتصفح، ولا يستطيع المعلّم الاطلاع عليه.
- يمكن تنزيل نسخة احتياطية (JSON) واستعادتها، أو مسح التقدّم، من صفحة «عن المنصة».
- لا توجد كلمات مرور أو مفاتيح سرية في الكود، ولا خدمات خارجية مدفوعة أو أدوات تتبّع. الخط (Tajawal) مضمّن محليًا عبر `@fontsource`.

## التقنيات

Next.js 16 (App Router، تصدير ثابت) · React 19 · TypeScript · Tailwind CSS 4 · Vitest · Playwright.

## التشغيل المحلي

المتطلبات: Node.js 20.9 أو أحدث (يُنصح بالإصدار 22، انظر `.nvmrc`).

```bash
npm install
npm run dev          # خادم التطوير على http://localhost:3000
```

## الفحوص والبناء

```bash
npm run typecheck    # فحص TypeScript
npm test             # اختبارات الوحدات (Vitest): بنك الأسئلة، الخطة، محرك الاختبارات، التقدّم والتخزين
npm run build        # بناء نسخة ثابتة في المجلد out/
npm start            # معاينة نسخة البناء محليًا على http://localhost:3000
npm run test:e2e     # اختبارات المتصفح (Playwright) بمقاسي حاسوب وهاتف — تتطلب تنفيذ build أولًا
npm run check        # typecheck + test + build معًا
```

تحتاج اختبارات المتصفح إلى Chromium: نفّذ `npx playwright install chromium`، أو حدّد مسار متصفح مثبّت عبر المتغير `CHROMIUM_PATH`.

## النشر على Netlify

المشروع مُعدّ كموقع ثابت (`output: "export"`)، والإعدادات موجودة في `netlify.toml`:

| الإعداد | القيمة |
|---|---|
| Build command | `npm run build` |
| Publish directory | `out` |
| Node version | `22` |

**الطريقة 1: من GitHub**
1. ادخل إلى [app.netlify.com](https://app.netlify.com)، ثم **Add new site** ← **Import an existing project**.
2. اختر المستودع، وسيقرأ Netlify الإعدادات من `netlify.toml` تلقائيًا.
3. اضغط **Deploy**. لا حاجة إلى أي متغيرات بيئة أو مفاتيح.

**الطريقة 2: من سطر الأوامر**
```bash
npm install -g netlify-cli
netlify login
npm run build
netlify deploy --dir=out          # نسخة معاينة
netlify deploy --dir=out --prod   # نشر نهائي
```

يضيف `netlify.toml` أيضًا ترويسات أمان أساسية، وتخزينًا طويل الأمد للملفات الثابتة، وصفحة 404 عربية.

## النشر على GitHub Pages

يحتوي المستودع على سير عمل جاهز في `.github/workflows/deploy-pages.yml`. يفحص المشروع (TypeScript واختبارات الوحدات)، ثم يبنيه وينشره على GitHub Pages تلقائيًا عند كل دفع إلى الفرع `main` (أو فرع التطوير الحالي).

**التفعيل (مرة واحدة فقط):**
1. افتح المستودع على GitHub ← **Settings** ← **Pages**.
2. تحت **Build and deployment** اختر **Source: GitHub Actions**.
3. افتح تبويب **Actions** ← **Deploy to GitHub Pages** ← **Run workflow** (أو ادفع أي تغيير).
4. بعد انتهاء التشغيل يظهر الرابط في صفحة Pages وفي نتيجة سير العمل:
   `https://bashirsaid.github.io/muhoben/`

**ملاحظات:**
- الموقع يُنشر تحت مسار فرعي (`/muhoben/`)، ويضبطه سير العمل تلقائيًا عبر المتغير `BASE_PATH`. لا حاجة لتغيير أي شيء في الكود.
- لتجربة هذا المسار محليًا:
  ```bash
  BASE_PATH=/muhoben npm run build
  BASE_PATH=/muhoben npm start        # http://localhost:3000/muhoben/
  BASE_PATH=/muhoben npm run test:e2e
  ```
- GitHub Pages مجاني للمستودعات العامة. وإذا جُعل المستودع خاصًا فيلزم اشتراك مدفوع في GitHub.
- يمكن استخدام GitHub Pages وNetlify معًا. نسخة Netlify تعمل على جذر النطاق دون مسار فرعي.

## بنية المشروع

```
src/
  app/                    الصفحات (App Router)
    page.tsx              لوحة الطالب
    plan/                 الخطة (30 يومًا)
    day/[day]/            صفحة اليوم: الدرس + الأمثلة + الأسئلة
    practice/             التدريب الحر
    exam/                 الاختبارات الشاملة بمؤقت
    results/              التقارير وسجل الاختبارات
    about/                عن المنصة، والخصوصية، وإدارة البيانات
  components/             مكونات قابلة لإعادة الاستخدام (QuizRunner وQuestionView وQuizReport والرسوم…)
  data/                   المحتوى، منفصل عن الواجهة
    topics.ts             المجالات الستة
    plan.ts               الخطة التدريبية (30 يومًا)
    questions/            بنك الأسئلة الأصلية (ملف لكل مجال)
  lib/                    منطق مستقل عن الواجهة
    quiz.ts               اختيار الأسئلة، والخلط، وحساب النتائج
    progress.ts           التقدّم، والمستويات، والاقتراحات
    storage.ts            طبقة التخزين (الواجهة ProgressRepository)
    types.ts              الأنواع المشتركة
tests/                    اختبارات الوحدات
e2e/                      اختبارات المتصفح
scripts/serve-out.mjs     خادم ثابت بسيط لمعاينة نسخة البناء
```

### إضافة أسئلة

أضف الأسئلة إلى الملف المناسب في `src/data/questions/` عبر `defineOriginalQuestions`. اكتب التعابير الرياضية بين علامتي `$...$` لتُعرض من اليسار إلى اليمين. يتحقق `npm test` تلقائيًا من سلامة البنية (معرّف فريد، ورقم إجابة صالح، وعدم تكرار الخيارات…).

لا تُضف أسئلة رسمية أو محمية بحقوق النشر. أي مواد مرخّصة مستقبلًا يجب أن تُعرَّف بنوع المصدر `licensed` مع ذكر الجهة والترخيص.

## التطوير لاحقًا (حسابات وقاعدة بيانات)

- كل الوصول إلى بيانات التقدّم يمر عبر الواجهة `ProgressRepository` في `src/lib/storage.ts`. لإضافة حسابات للطلاب والمعلّمين، أنشئ مستودعًا يتصل بواجهة برمجية (API) ومرّره إلى `ProgressProvider` دون تغيير الصفحات.
- عند الحاجة إلى خادم: أزل `output: "export"` من `next.config.ts` واحذف `publish` من `netlify.toml`؛ سيستخدم Netlify محوّل Next.js تلقائيًا لدعم Route Handlers والوظائف الخادمية.
- تُحفظ المفاتيح السرية في متغيرات بيئة Netlify، وليس في كود الواجهة. وعند جمع أي بيانات لطلاب قاصرين، يلزم الحصول على موافقة الأهل والاكتفاء بالحد الأدنى من البيانات.
